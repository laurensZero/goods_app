谷子收纳 · Auth 邮件模板

六封系统邮件的 HTML 源码与预览 · 发件域名 goodsapp.de5.net · 复制到 Supabase 后台即可使用

先修：验证链接为什么「没用」

你邮件里的 redirect_to=http://localhost:3000 是错误入口：

  • 本地 Vite 端口是 5173，不是 3000
  • 生产环境应是 https://goodsapp.de5.net 或 https://goods-app.pages.dev
  • 点击验证后若跳到打不开的地址，看起来像验证失败；服务端其实可能已通过

Supabase 后台操作：

  1. 打开 Authentication → URL Configuration
  2. Site URL 填生产 Web 入口，例如 https://goodsapp.de5.net
  3. Redirect URLs 至少加上：
    https://goodsapp.de5.net
    https://goodsapp.de5.net/*
    https://goods-app.pages.dev
    https://goods-app.pages.dev/*
    http://localhost:5173
    http://localhost:5173/*
  4. 保存后，再用全新邮箱注册一次，新邮件里的链接才会指向正确地址
验证后去哪儿： App 注册 → redirect 为 https://goodsapp.de5.net/auth.html?src=app，自动拉起 App； 网页注册 → 仍回到网页版。Redirect URLs 请包含 https://goodsapp.de5.net/*。 AUTH_WEB_ORIGIN 已设为 https://goodsapp.de5.net。 Android 需安装含 goodsapp://auth 的新包。
QQ/微信内点邮件链接： 内置浏览器通常拦自定义 scheme（goodsapp://）， 拉起 App 会失败，但邮箱验证本身已成功。 auth.html 会提示「在浏览器中打开」；也可直接用网页版登录。 系统邮件 App / Chrome / 系统浏览器可正常尝试拉起 App。
代码侧已修改：注册时会带上 emailRedirectTo（与魔法链接一致）。Capacitor/Android 场景请在 src/config/supabase.js 里把 AUTH_WEB_ORIGIN 设为公网 Web 地址，例如 https://goodsapp.de5.net，否则手机上打开邮件链接可能落到错误 origin。
密码重置走的是 App 内 OTP 流程（填验证码），模板里 {{ .Token }} 才是主路径；链接按钮是备用。
邮件头像 Logo 使用公网地址 https://goodsapp.de5.net/assets/logo-email.png。 文件已在 public/assets/logo-email.png，随 Cloudflare Pages 部署后即可加载。 部署前请先确认该地址能打开；打不开时邮件里会没有图（正文与按钮仍可用）。

如何粘贴到 Supabase

  1. 后台 Authentication → Emails
  2. 点开对应邮件类型（Confirm signup / Magic Link / Change Email / Reset Password / Invite / Reauthentication）
  3. Subject 填中文标题（见下方对照表）
  4. Message HTML 粘贴本目录对应 .html 文件完整源码（保留 {{ .… }} 变量）
  5. Save。用新邮箱注册 / 点魔法链接各测一封
Supabase 模板名Subject 建议文件
Confirm signup 请验证你的谷子收纳账号邮箱 confirm-signup.html
Magic Link 你的谷子收纳登录链接 magic-link.html
Change Email Address 确认更换谷子收纳账号邮箱 change-email.html
Reset Password 谷子收纳密码重置验证码 reset-password.html
Invite User 邀请你加入谷子收纳 invite-user.html
Reauthentication 谷子收纳安全验证验证码 reauthentication.html

模板变量必须原样保留：

  • {{ .ConfirmationURL }} — 验证 / 登录 / 换绑链接
  • {{ .Token }} — 验证码（重置密码、再认证）
  • {{ .Email }}、{{ .SiteURL }} — 可选，当前模板未用
